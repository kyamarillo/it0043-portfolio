Project Title: Web Design Personal Portfolio Website

Overview:
It is a personal website created to showcasing my background, skills, and more. It serves as an online resume to explore about me, my skills, and find ways to contact me.

This wesbite was developed with HTML, CSS, and JS. This features responsive layout for mobile and desktops, interactive elements, and light and dark themes to provide user a better browsing across different screen sizes and brightness.

Features:
Home Page: Introduction of the user and provides overview of the portfolio
About Page: Presents personal information and background
Skills Page: Displays skills and knowledge
Contact Page: Provide contact information to inform the user
Responsive Design: Adjusts the website layout in different screen sizes
Light and Dark Mode: Allows user to toggle light and dark theme button for better view
Navigation Menu: Provide quick access to different pages of the website
Project Cards: Displays three projects
Visitor Information: Uses LocalStorage to remember the visitor's name and last visit
Form Validation: Checks the contact form inputs before submission

Technologies:
HTML - The foundation / structure of the website
CSS - The formation of the layout and responsive design
JS - The functionality of the interactions and behavior
LocalStorage - Stores visitor information and theme preferences in the browser
InfinityFree - To host and publish the website online

Deployment:
The website is hosted by InfinityFree

To deploy the website, create the domain account to activate the subdomain. Click subdomain and pick ifree.page and name the domain. Go to file manager and upload the website files and folders into the htdocs directory of the hosting account. Make sure the homepage is named index.html, it must be lowercase letters and that the file paths are correct.
